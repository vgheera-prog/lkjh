2-Minute Supabase Database Setup

If your Supabase database is new, you only need to run the included SQL script once to create the tables (orders and menu_items) and allow orders to be stored in the cloud.

  1. Open your Supabase Project Dashboard
  2. Click on SQL Editor on the left navigation bar.
  3. Click New Query.
  4. Click the button "Copy Full SQL Setup Script" on the left, paste into the editor, and click RUN!
  5. That's it! Your PostgreSQL database is live and synchronized with real-time orders and menu items.
Zero Downtime Fallback: The website and admin panel automatically store all customer orders in persistent browser memory even before running the SQL script, so no customer order is ever lost!
